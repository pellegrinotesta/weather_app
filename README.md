# weather_app
App meteo che permette di consultare le condizioni meteo attuali di qualsiasi città inserita dall’utente. ’app utilizza l’API Geocoding di Open-Meteo per trovare le coordinate geografiche di quella città. Successivamente, invia queste coordinate all’API di previsione meteo di Open-Meteo per ottenere i dati meteorologici aggiornati.
